# Bank-Loan-Analytics
# 🏦 Bank Loan Analysis Dashboard

## Project Overview
- Developed an interactive **Bank Loan Analysis Dashboard** using Microsoft Excel.
- Analyzed bank loan data to understand loan distribution, customer behavior, and financial risk.
- Used charts, KPIs, and slicers to make the data easy to understand.
- Helped identify important trends in loan amounts, interest rates, and customer debt.

## Project Objectives
- Analyze the total loan amount.
- Understand the average interest rate and Debt-to-Income (DTI) ratio.
- Track the number of customers and total revolving balance.
- Compare verified and non-verified loans.
- Analyze loan trends by year, quarter, month, and other categories.

- **Total Revolving Balance:** 531.5M

## Dashboard Features
- Year-wise loan amount analysis.
- Loan verification status comparison.
- Customer distribution by state.
- Home ownership analysis.
- Loan amount comparison across categories.
- Interactive filters for year, quarter, month, grade, and revolving balance.

## Key Insights
- The dashboard shows changes in loan amounts across different years.
- Verified loans account for approximately 68% of the displayed loan distribution.
- The dashboard helps compare customer home ownership categories.
- Interactive filters make it easier to explore specific periods and customer segments.
